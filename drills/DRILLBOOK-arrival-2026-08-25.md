# Drillbook — arrival — 2026-08-25

Written before anybody was staffed. Not edited afterwards.

## Situation to create

A person who has never heard of memhouse is handed one file and a sentence, on a machine
where memhouse is not installed. By the end, they should have their memory shipping and
have found something they worked on before.

Nothing about *how* that goes is written here.

## Roles staffed

| role | agent kind | where |
|---|---|---|
| **arriver** | `claude` | `testbed`, own home, no checkout of this repository anywhere on the machine |
| **sharer / principal** | the runner | answers only as the person who sent the file would |

## What the arriver is given

The invite file, and this and nothing else:

> Here's your memhouse invite — the attached file gets you set up. Shout if you get stuck.

They are **not** told: what memhouse is, that a CLI exists, what to install, what the file
contains, that skills exist, or that anything should be shipped.

## What the runner may answer

Only what the sender would: *yes, go ahead*, *it's your own machine*, *whatever handle you
like*. Never explain memhouse, never name a command, never say which file to read.

## Watched

`memhouse whoami` and the house's row counts from a separate seat, so the drill can tell
what the arriver actually achieved from what they believe they achieved.

## Asked at the end

1. What did memhouse fail to tell you?
2. At any point, did you have to guess?
3. Was there a moment you could not tell whether it had refused you or broken?
